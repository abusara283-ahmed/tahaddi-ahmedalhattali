# تحدّي العباقرة – تطبيق أندرويد (APK)

مسابقات الرياضيات المسلية والمسابقات الدينية للأستاذ أحمد الهطالي، تعمل على الهاتف والتابلت دون إنترنت (الخطوط والمكتبات مضمّنة).

## تنزيل التطبيق
افتح صفحة **Releases** في هذا المستودع، ونزّل ملف `tahaddi-alabaqira.apk` من أحدث إصدار، ثم افتحه على الجهاز واسمح بالتثبيت من هذا المصدر عند السؤال.

## كيف يُبنى
عند كل رفع إلى الفرع `main` يبني GitHub Actions ملف APK موقّعاً ويضعه في صفحة Releases (سير العمل: `.github/workflows/build-apk.yml`). ويمكن تشغيله يدوياً من تبويب **Actions** ← «بناء APK تحدي العباقرة» ← **Run workflow**.

## تحديث المحتوى
1. حدّث ملف `index.html` لتحدّي العباقرة.
2. شغّل: `python3 tools/prepare_www.py <مسار index.html> <مجلد vendor>` (يحوّل روابط المكتبات إلى نسخ محلية ويضيف حفظ الملفات وزر الرجوع).
3. ارفع التغييرات إلى `main`، فيُبنى إصدار جديد يُثبَّت فوق القديم دون حذف الأسئلة المحفوظة.

## ما يضيفه التطبيق على نسخة الويب
- يعمل دون إنترنت، عدا الميزات السحابية (لوحة المعلم، مسابقة PIN، الواجبات).
- حفظ ملفات الأسئلة والنتائج في: التنزيلات ← تحدي العباقرة.
- زر الرجوع يعيدك إلى الرئيسية، ومن الرئيسية يغلق التطبيق.

## التوقيع
يُوقَّع التطبيق بمفتاح ثابت محفوظ في أسرار المستودع (`KEYSTORE_B64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`) حتى تُثبَّت التحديثات فوق الإصدار السابق. لا تحذف هذه الأسرار.
